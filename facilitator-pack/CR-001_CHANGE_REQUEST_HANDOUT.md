# CR-001 — Identify the Workshop

Organizers run multiple workshops and need to know which workshop each feedback submission belongs to.

Update the application so each new feedback submission includes a required **workshop topic**.

For this POC:

- workshop topic is free text;
- it is required;
- maximum length is 100 characters;
- organizer review must display it;
- existing feedback records that do not contain a workshop topic must still remain viewable;
- all existing rating/comment behavior must continue working.
